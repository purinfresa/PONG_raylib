# Pong

Proyecto personal del videojuego Pong 2D, desarrollado en Java 
utilizando la biblioteca raylib.

## Tecnologías usadas

- Java
- Raylib

## Descripción

Es un videojuego basado en el clásico Pong 2D de los años 70. 
Este proyecto está desarrollado con el objetivo de reforzar conocimientos 
y practicar gráficos, interacciones y movimientos.
